How VeriVision Works

Visual (ConvNeXt)

Analyzes raw pixels to detect semantic inconsistencies, unnatural blending, and AI-generated texture artifacts using a deep convolutional network.

Spectral (FFT)

Transforms the image into a 1D frequency profile to spot invisible grid patterns left behind by AI upsampling and diffusion processes.

Noise (SRM)

Strips away image content using high-pass filters to evaluate underlying matrix noise, looking for synthetic digital signatures.

Meta-Model

A logistic regression algorithm acts as the judge, intelligently weighing the three experts' opinions based on dynamic OpenCV lighting/blur gating.
