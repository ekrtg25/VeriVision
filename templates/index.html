Архитектура & Принципы работы VeriVision

VERSION 3.5.0 // ROBUST MOE
[01 // Perceptual Backbone]
Fine-Tuned DINOv2 & Dense XAI
Ядром детектора выступает модель DINOv2-Base (ViT-B/14) с частичной разморозкой верхних блоков внимания. Входной классификатор объединяет глобальный контекст CLS и усредненные патчи Spatial Mean (1536-мерное пространство). Реализована оценка каждого из 1369 патчей для построения 2D карт локализации артефактов без вычислительных накладных расходов.
PyTorch DINOv2 ViT-B/14 Dense Patch XAI 518×518 High-Res
[02 // Physical Forensics]
Физический след сенсора & Спектр
Помимо семантики, система анализирует физические свойства формирования кадра:

• PRNU: извлечение высокочастотного отпечатка кремниевой матрицы фотокамеры.
• ELA: выявление ступенчатых градиентов сжатия для детекции Inpainting.
• 2D FFT: поиск дифракционных решеток и артефактов латентного VAE.
Sensor PRNU JPEG ELA FFT 2D Spectrum SRM Filters
[03 // Gating & Calibration]
Dynamic Gating & Robust Fusion
Главная проблема классической форензики — ложные срабатывания на сжатии мессенджеров (Telegram/WhatsApp). VeriVision использует алгоритм Dynamic Gating: при обнаружении сильной JPEG-компрессии система динамически снижает веса ELA/FFT, передавая приоритет инвариантному DINOv2 и защищая реальные фото от ложных обвинений.
