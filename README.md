# 👁️ VeriVision

Лёгковесный гибридный детектор AI-сгенерированных изображений. В фокусе — детекция генераций **Midjourney v6** и других современных диффузионных моделей, устойчивых к обнаружению тяжёлыми детекторами общего назначения (CLIP-подобными).

## Идея

Вместо одной тяжёлой модели — три узких независимых эксперта, каждый ловит свой класс артефактов, плюс честный фьюжн их вероятностей.

| Эксперт | Метод | Что ловит |
|---|---|---|
| 🧠 Визуальный | ConvNeXt-Tiny | Семантические артефакты, "поплывшие" текстуры |
| 📡 Спектральный | FFT + Random Forest | 1D радиальный профиль мощности — следы апсемплинга, шахматные паттерны диффузии |
| 🔬 Шумовой | SRM (Spatial Rich Models) + Random Forest | Статистика высокочастотного синтетического шума |

### Фьюжн: Confidence-Weighted Logit Fusion

Простое усреднение трёх вероятностей "сплющивает" итоговую уверенность к 45–60% даже на однозначных случаях: если один эксперт уверен (0.85), а другой ничего не понял (0.15 — по сути не знает), среднее размывается до 0.5.

Решение — взвешенное суммирование в пространстве логитов, где вес каждого эксперта пропорционален его собственной уверенности (`|logit(p)|`). Эксперт, который "не знает" (`p ≈ 0.5` → `logit ≈ 0`), автоматически перестаёт участвовать в голосовании, вместо того чтобы тянуть уверенного эксперта к центру:

```python
w_i = |logit(p_i)| ** k              # k = 2.0
fused_logit = Σ(w_i · logit(p_i)) / Σ(w_i)
final_prob = sigmoid(fused_logit)
```

Реализация — `src/serving/ensemble.py`, класс `HybridEnsembleDetector`.

**Известное ограничение / следующий шаг:** сырые вероятности `fft_prob`/`srm_prob` от Random Forest пока не откалиброваны (RF систематически занижает уверенность из-за природы голосования деревьев). Раздельная Platt-калибровка каждого эксперта перед фьюжном — в планах.

## Метрики (OOD, фокус на MJv6)

- **Accuracy:** 92.5%
- **Recall (Fake):** 96.0%
- **EER:** 8.0%

## Структура проекта

```
VeriVision/
├── app.py                     # Streamlit-приложение — точка входа

├── src/
│   ├── serving/                # инференс-код
│   │   ├── ensemble.py         #   HybridEnsembleDetector — фьюжн трёх экспертов

│   ├── models/                 # архитектуры экспертов

│   │   ├── fft_module.py       #   SpectralAnalyzer (спектральный эксперт)
│   │   └── srm_module.py       #   SRMAnalyzer (шумовой эксперт)
│   ├── data/                   # датасеты и трансформации
│   └── evaluation/             # метрики, тесты на устойчивость
├── research/
│   ├── archive/                # отброшенные по метрикам архитектуры (CLIP-probe, DIRE, старый Frequency-детектор)
│   └── scripts/                # тренировочные скрипты, по этапам эксперимента (01…06)
├── experiments/results/        # журнал экспериментов — хронология решений
├── docs/                       # архивная документация (описывает более ранние этапы проекта)
└── models/                     # веса Random Forest (rf_spectral.pkl, rf_srm.pkl)
```

Полная история экспериментов и почему были отброшены те или иные подходы — в `experiments/results/`.

## Установка

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Требуются веса моделей в `models/`:
- `baseline_weights.pth` — веса ConvNeXt-Tiny (не входят в репозиторий, обучаются через `research/scripts/05_hybrid_ensemble/`)
- `rf_spectral.pkl`, `rf_srm.pkl` — веса Random Forest (входят в репозиторий)

## Запуск

**Веб-интерфейс:**
```bash
streamlit run app.py
```
Загрузите изображение — приложение покажет вердикт ансамбля и разбивку по каждому эксперту, порог срабатывания настраивается ползунком.

**Оценка на OOD-датасете:**
```bash
python scripts/prepare_ood_datasets.py   # если данные ещё не скачаны
python scripts/evaluate_ood.py
```

## Обучение экспертов

Тренировочные скрипты сгруппированы по этапам эксперимента в `research/scripts/`:

- `01_baseline/` — первая ResNet/ConvNeXt-версия визуального эксперта
- `02_clip_vit_l/` — эксперименты с CLIP/ViT-L (отброшены, см. `docs/EXPERIMENTS_ARCHIVE.md`)
- `03_dire/` — эксперименты с DIRE-реконструкцией (отброшены)
- `04_spectral_srm/` — обучение спектрального и шумового экспертов
- `05_hybrid_ensemble/` — финальное дообучение визуального эксперта под гибридный ансамбль
- `06_calibration/` — попытки калибровки порога/вероятностей

## Технологический стек

PyTorch / torchvision (ConvNeXt), scikit-learn (Random Forest), OpenCV, Streamlit.
