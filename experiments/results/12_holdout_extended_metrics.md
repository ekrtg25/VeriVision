# Эксперимент №12: Расширенные метрики Hold-out оценки (ROC-AUC & Confusion Matrix)

**Дата:** Август 2026
**Контекст:** Дополнение к оценке финального Stacking-ансамбля из Эксперимента №8 (Accuracy 86.0%, F1 0.89 на Hold-out выборке из 1500 изображений).

## Методология
Для комплексной оценки качества классификации на той же Hold-out выборке (1500 изображений) построены матрица ошибок и ROC-кривая.

## Результаты

- **ROC-AUC Score:** **0.938** — метрика показывает превосходную разделяющую способность ансамбля вне зависимости от выбранного порога (Threshold).
- **Confusion Matrix Analysis:** При пороге 0.50 система минимизировала количество False Positives (ложных обвинений реальных фотографий), что является приоритетом для систем контент-модерации, сохраняя при этом Recall на уровне 88%.

## Вывод
ROC-AUC 0.938 подтверждает, что высокая точность стекинг-ансамбля из Эксперимента №8 не зависит критично от выбора порога, а Confusion Matrix показывает разумный баланс между Precision и Recall при пороге по умолчанию.
